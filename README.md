# Training Deployment Tracker – Europe L&D Portfolio

An MIS tracker for learning and development (L&D) deployment, built on **5,000 sample course offerings** (Jan 2025 – Dec 2026) across 12 courses and 8 European regions.

## Data
One row per offering: seats, nominations, cancellations, no-shows, L1 feedback score (1–5), budget and actual cost.

## Build
- KPI cards
- SUMIFS / AVERAGEIFS tables by course, region and delivery mode
- Flags for high no-shows and overspend
- Bar charts, and key findings written as formulas so they update with the data

## Key findings
- **79.0%** fill rate and **13.6%** no-show rate overall
- Virtual sessions: 16.7% no-shows vs 5.0% for classroom
- Classroom sessions ran **11.1% over budget**
- Project Management Essentials: highest no-show rate (21.9%) and lowest L1 score (3.85)
